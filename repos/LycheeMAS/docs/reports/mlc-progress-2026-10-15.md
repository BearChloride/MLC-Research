## Advancing Collaborative Debates with Role Differentiation through Multi-agent Reinforcement Learning

（ACL 2025 Long Papers, `2025.acl-long.1105`；汇报日期 2026-10-15）

### 当前进度：

1、基于 LycheeMAS 搭建复现环境并完成数据落位：conda 环境 `LycheeMAS`（Python 3.12 + CUDA 版 torch，RTX 4060 Laptop 8GB），把论文使用的 **7 个数学数据集**（GSM8K / AddSub / SingleEQ / MultiArith / ASDiv / SVAMP / MATH）全部接入框架的 benchmark 注册与 prepared 缓存，实现本地数据免联网加载；并通过 gold 自检（把标准答案当预测喂进评分器）确认 7/7 数据集的答案解析与评分口径完全一致。

2、基于 LangGraph 基线脚本构建 **single（单智能体）** 与 **planner-solver-verifier 三智能体链式结构**，选择 GSM8K 任务集，实现自然语言通信消息生成与解析、多轮执行轨迹采集、答案抽取、评分计算，以及 accuracy / token / latency 三类指标的统一落盘。

3、用本地 **Qwen3-0.6B** 模型（ModelScope 下载，bf16 直跑）完成 GSM8K **100 题**对照实验：采用固定随机种子（seed=0，从 1319 题测试池中随机抽取），抽样下标写入 config 快照以保证子集可精确复现；两条基线各复跑验证确定性。同时配套实现三件工具：**固定种子抽样**、**评分误判审计**（不改官方口径，另出严格数值口径）、**配对显著性检验**（McNemar）。

### 后续计划：

1、当前两条基线均使用同一个 Qwen3-0.6B 模型，仅用于验证链路；后续迁移至更大模型（Qwen3-4B/8B，4-bit 量化）复跑，确认结论在合理规模下是否变化。

2、补齐论文的两个对照基线（Multi-Agent(Debate) 与 LLMAgora），并搭建辩论图（N 辩手 × R 轮，按轮展开成静态 DAG），对齐 MLC 的执行形态。

3、在 LycheeMAS 的 **prerun（运行前优化）接缝**实现 MLC 本体：角色感知策略（role-aware RNN）+ multi-LLM mixing network + 角色分化模块，离线训练产物落 JSON，再经 `apply` 即插即用挂回图，注册为 `pre_run_optimizer/mlc`。

4、把审计口径与配对检验固化为常规流程：后续每次方法对照都同时报官方/严格两组数字与 McNemar p 值，避免用"多对一题"下结论。

### 存在的问题：

1、**论文无官方代码、无超参数表。** 正文未提供代码链接，GitHub 检索也无官方实现；学习率、优化器、α/β 权重、隐变量维度、RNN 结构、mixing network 层数等全部缺失，需自行确定并在文档中声明与原版的差异。

2、**奖励函数定义模糊。** 论文只写"生成回复与正确答案的余弦相似度"，未说明是文本编码器相似度还是答案匹配；在数学题上该设计较脆弱，这是能否复现出论文增益的最大不确定点。

3、**算力受限，必须缩比。** 论文用 Llama2-7B/13B、Llama3-8B、Mistral-7B 等底座，本机 8GB 显存跑不了 13B；当前用 0.6B 仅为验证链路，缩比范围需在复现报告中明确标注。

4、**评分口径存在误判，但不能修改（已用审计口径绕过）。** `score_exact` 在数字不等时会退化为"字符串包含"判断：gold=5、预测 `\boxed{3.25}` 会被判对（`5` 是 `325` 的子串）。实测误判率约 1%（single 1/100、chain3 3/100）。由于口径要与团队/历史结果保持可比，**不修改打分器**，改为：① 另出"严格数值口径"（抽取数字后按数值比较）双数并报；② 用 McNemar 配对检验替代"多对一题"式的判断。两种口径下结论一致（差异均不显著）。

5、**链式结构会改变作答形态。** 观察到一个典型样本：gold=230，chain3 的 verifier 输出"80 miles 和 150 miles"（两分量之和恰为答案），未给总和而被判错。这类样本既非推理错也非判分错，建议在后续实验中把"格式/表述异常"单独作为诊断列统计，不混入准确率。

6、**数据侧的已知取舍。** MATH train 有 4/7500 条缺 `\boxed{}`（仅训练素材，已计数跳过）；ASDiv 有 146/2305 条非数值答案（Yes/No、时刻、人名），保留原文评分；论文未公布随机种子，跨论文只能比相对提升。

7、**产物边界需要确认。** MLC 会微调 LLM 自身策略权重，而 LycheeMAS 的 prerun `apply` 阶段只改图（prompt / adjacency）。是"完整复现（含策略权重）"还是"先做角色与提示层面的运行前优化"，需要先与老师对齐；角色/模型的写回通道（`graphview.rebuild` 目前只支持 prompts / adjacency）也需一并确认。
